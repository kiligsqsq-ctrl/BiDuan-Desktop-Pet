# 彼端桌宠当前功能说明

本文对应 **0.4.2 MVP**，用于说明程序现在真实可用的能力、具体行为以及尚未实现的边界。

## 1. 桌面角色

- 无标题栏透明窗口，桌面只显示角色、气泡和必要内容。
- 默认保持在其他窗口上方，可在设置中关闭置顶。
- 支持调整整体透明度和一键回到屏幕左上角。
- 鼠标按住并移动角色即可拖动；拖动时播放专用 GIF，松手后恢复当前状态动作。
- 双击角色打开“情侣小窝”，右键可打开快捷菜单。
- 首次启动播放随机招呼动画，之后进入当前状态动画。
- 角色位置、透明度、置顶选项会保存在本机。

## 2. 状态与动作

当前动作包共包含 11 类状态、61 个状态动画和 1 个拖拽动画：

| 状态 | 动作数量 | 用途 |
| --- | ---: | --- |
| 打招呼 | 3 | 启动招呼或日常问候 |
| 工作 | 10 | 工作、学习、加班等忙碌场景 |
| 吃饭 | 4 | 用餐状态 |
| 睡觉 | 7 | 睡眠和休息状态 |
| 开心 | 11 | 开心、庆祝等积极情绪 |
| 难过 | 8 | 低落、委屈等情绪 |
| 生气 | 1 | 生气状态；当前素材只有一个变体 |
| 无聊 | 8 | 无聊、等待陪伴等状态 |
| 洗澡 | 5 | 洗澡状态 |
| 上厕所 | 2 | 暂时离开状态 |
| 甜蜜 | 2 | 想念、贴贴等亲密状态 |

同一状态内的动作会随机轮换。用户可以选择 10 秒、30 秒、60 秒或 5 分钟四个轮换档位，默认 60 秒。

### 桌面状态来源

“动作”页提供两个互斥选项：

- **显示我的状态**：本机选择状态后，桌面角色立即切换到对应动作。适合单机使用、预览动作或表达自己的近况。
- **显示 TA 的状态**：桌面角色只表现对方同步过来的状态。本机修改自己的状态时，只会保存并发送给对方，不会改变本机角色。

状态来源属于本机偏好，不会同步给对方。两个人可以各自选择不同模式。

## 3. 情侣小窝

主菜单包含五个可滚动页面：

- **陪伴**：设置我的状态、动作轮换速度，查看陪伴值并发送轻互动。
- **动作**：选择桌面状态来源，浏览 11 类动作并切换预览。
- **互动**：配置共享文件夹同步、立即同步、手动导入/导出和快速留言。
- **留言**：写入、浏览和查看双方留言。
- **设置**：修改双方昵称、宠物名字、日期、窗口和开机启动选项。

所有页面支持右侧纵向滚动条；窗口较小时也可以用鼠标滚轮查看完整内容。

## 4. 温柔互动与陪伴值

当前互动包括：

- 轻轻碰你
- 抱抱
- 喂糖
- 休息

互动会生成一条记录和桌面气泡，并改变心情、能量、想念三个陪伴值。陪伴值会随时间缓慢变化，用来提供轻量的照顾感，不代表真实情绪判断。

## 5. 纪念日与留言

- 保存“在一起日期”，计算在一起的天数。
- 保存纪念日日期，显示下一次纪念日倒计时。
- 留言信箱保留最近的情侣留言。
- 提供“我想你啦”“记得喝水”“到家告诉我”等快捷留言。
- 留言和互动均带唯一标识，重复导入同一同步数据时不会反复追加。

## 6. 双机同步

### 共享文件夹自动同步

双方选择同一个 OneDrive、坚果云或其他云盘共享目录后，程序每隔约 8 秒执行一次本地同步：

1. 各自写入只属于本设备的 JSON 文件。
2. 云盘客户端负责把文件传到另一台电脑。
3. 彼端读取对方文件，合并昵称、状态、留言和互动。
4. 新内容通过桌面气泡和 Windows 通知展示。

### 手动同步

无法使用共享云盘时，可以导出彼端 JSON 文件并发送给对方，由对方手动导入。

### 当前同步边界

- 不是彼端自建的实时云服务，速度取决于第三方云盘。
- 没有情侣绑定码、账号登录、设备管理和服务端离线消息。
- 同步 JSON 没有端到端加密，不建议放入公开或不可信目录。
- 多个候选设备文件目前采用较简单的时间和去重策略，不是完整的冲突解决系统。

## 7. Windows 集成

- 软件名称和应用图标为“彼端”。
- 右下角系统托盘支持显示/隐藏、快速状态、抱抱、开机启动和退出。
- 单实例运行，重复启动时提示程序已经运行。
- 支持注册表开机启动。
- PyInstaller 构建单文件 `BiDuan.exe`。
- Inno Setup 构建中文安装向导、桌面快捷方式、开始菜单和卸载入口。

## 8. 本地数据

数据默认保存在 `%APPDATA%\BiDuanPet\state.json`，包括：

- 双方昵称和状态
- 桌宠位置与本机显示偏好
- 纪念日和在一起日期
- 陪伴值、留言和互动
- 同步目录及设备标识

卸载程序不会主动删除该目录，重新安装后可以继续使用。损坏的状态文件会被改名备份，并重新生成默认数据。

## 9. 当前尚未实现

- 官方账号与情侣绑定
- 真正的互联网实时同步
- 端到端加密和完整隐私控制
- 自定义完整 GIF 动作包上传与管理
- AI 照片生成 Q 版角色
- 自动更新、崩溃上报和版本回滚
- 照片墙、共同愿望、纪念日时间线
- 移动端和 macOS 客户端
- 商城、会员和支付

这些内容属于后续规划，不应被当作当前版本已支持的功能。
